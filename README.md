# Nib

**NovelAI Diffusion V5 프롬프트 라이브러리** — 크롬 확장.

자주 쓰는 태그 묶음을 저장해두고, NovelAI 화면 옆 사이드 패널에서 클릭 한 번으로 넣고 뺍니다.

> 내부 구조는 [ARCHITECTURE.md](ARCHITECTURE.md), 고칠 때 주의할 것은 [MAINTENANCE.md](MAINTENANCE.md).

---

## 무엇을 해결하나

프롬프트를 메모장에 모아두고 복사해 붙이는 방식은 태그가 쌓일수록 무너집니다.
어떤 화풍을 썼는지 찾기 어렵고, 캐릭터가 둘 이상이면 어느 칸에 넣을지 헷갈리고,
넣은 태그를 빼려면 직접 지워야 합니다. Nib은 그 과정을 클릭 한 번으로 줄입니다.

---

## 설치

압축 파일이라면 **먼저 압축을 풉니다.** 압축된 채로는 설치할 수 없습니다.

1. Chrome 주소창에 `chrome://extensions`
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → `manifest.json`이 바로 안에 있는 폴더 선택
4. NovelAI 탭이 이미 열려 있었다면 **F5로 새로고침**

Chrome은 새 확장을 툴바에 자동으로 꺼내주지 않습니다. 주소창 오른쪽 **퍼즐 조각 아이콘** →
Nib 옆 **핀**을 누르면 고정됩니다. 아이콘을 누르면 사이드 패널이 열립니다.

처음이라면 설정(⋮)의 **예시 프리셋 채우기**로 9개를 넣어보고 감을 잡으세요.

**요구 사항** — Chrome 114 이상(사이드 패널 기능), NovelAI 이미지 생성 페이지.
빌드 과정 없음. 외부 통신 없음 — 네트워크로 나가는 것은 NovelAI 본래 요청뿐입니다.

### 배포와 업데이트

폴더 전체를 그대로 압축해 전달합니다. **`manifest.json`이 압축 파일 최상단에 바로 보이게** 담으세요.
폴더를 한 겹 더 감싸면 "매니페스트가 없다" 오류가 납니다. 문서(`*.md`)는 빼도 동작에는 지장이 없습니다.

업데이트는 새 폴더로 덮어쓴 뒤 `chrome://extensions`에서 Nib 카드의 **새로고침(↻)**.
콘텐츠 스크립트(`page.js`·`content.js`·`shared-ui.js`·`overlay.js`·`editor.js`·`queue.js`·`cleaner.js`·`viewer.js`)가 바뀌었다면 **NovelAI 탭도 새로고침**해야 합니다.
프리셋과 사용량 기록은 그대로 유지됩니다.

## 쓰는 법

- **카드 클릭** = 토글. 태그가 없으면 넣고, 이미 다 들어 있으면 뺍니다.
- 지금 적용 중인 프리셋은 **크림색 테두리**로 표시됩니다.
- **연필** = 편집/삭제 · **＋** = 새 프리셋 · **폴더＋** = 지금 탭에 새 폴더 · **지팡이** = 태그 정리
- **현재 내용 저장** = 지금 입력란 내용을 그대로 새 프리셋 초안으로 엽니다.
- **검색** — 프리셋 이름과 태그 내용을 함께 찾습니다.

### 어느 칸으로 들어가는가

프리셋마다 **기본 대상**이 있고 그 값이 목적지를 정합니다. 카드 아래 `화풍 → BASE`처럼 표시됩니다.

| 기본 대상 | 목적지 |
|---|---|
| `Base Prompt` | Base Prompt |
| `Undesired Content` | 전역 UC |
| `캐릭터 프롬프트` | 상단에서 선택한 **캐릭터 N번**의 Prompt |
| `캐릭터 UC` | 선택한 캐릭터 N번의 UC |

상단 `대상` 줄의 `캐릭터 1 / 2 …` 버튼은 캐릭터 프리셋이 몇 번으로 갈지를 고릅니다.
UC 프리셋이 실수로 Base에 들어가지 않도록 목적지는 프리셋 자신이 정합니다.

### 편집 창

편집 창은 사이드 패널이 아니라 **NovelAI 화면 위에** 뜹니다(패널 384px에서는 칸별 입력이
세로로 한없이 길어집니다). 사용량 창과 같은 창틀이고 잡아 옮길 수 있으며 자리를 기억합니다.

- `Esc` 닫기 · `Ctrl+Enter` 저장. 쓰던 내용이 있으면 닫기 전에 묻습니다.
- 열면 NovelAI 탭이 앞으로 나옵니다. NovelAI 탭이 없으면 열 수 없습니다.
- 저장은 확장 저장소에 바로 들어가고 패널 목록은 즉시 따라 바뀝니다.

### 북마크 · 폴더

카드에 마우스를 올리면 별표가 나타납니다. 등록하면 분류 줄의 **북마크** 칩으로 모아 봅니다.

폴더는 **모든 탭에서** 만들 수 있고, **폴더 안에 폴더는 없습니다**(한 겹).
폴더 줄을 클릭하면 접히고 펴지며 그 상태는 기억됩니다.

- **넣는 법 두 가지** — 카드를 끌어다 폴더 줄에 놓거나, 카드의 폴더 버튼으로 목적지를 고릅니다.
  폴더 버튼 목록에는 **다른 탭의 폴더도 전부** 나옵니다(끌어다 놓기로는 닿지 않는 곳에 넣을 때).
  폴더 안 카드를 끌면 목록 맨 위에 `폴더 밖으로 빼기` 자리가 나타납니다.
- **폴더를 지울 때는 안의 프리셋을 어떻게 할지 먼저 묻습니다** — `프리셋은 남기기`(폴더만 없애고
  안의 것을 밖으로 꺼냅니다) 또는 `프리셋까지 함께 지우기`. 각각 몇 개가 걸리는지 창에 적혀 있고,
  지우는 쪽은 한 번 더 확인합니다. 빈 폴더는 묻지 않고 확인만 받습니다.

**어느 탭에 어떤 폴더가 보이는가** — 그 탭에서 만든 폴더는 비어 있어도 보이고, 그 탭에 보이는
프리셋을 담고 있으면 어느 탭에든 보이고, `전체` 탭에는 모두 보입니다.
그래서 **폴더에 넣었다고 프리셋이 탭에서 사라지는 일은 없습니다.**
검색 중에는 걸린 것이 있는 폴더만 남고 자동으로 펼쳐집니다(저장된 접힘 상태는 건드리지 않습니다).

### 캐릭터 선택

캐릭터 프리셋을 누르면 어느 캐릭터에 넣을지 묻습니다. 각 칸의 현재 내용을 미리 보여주고,
누르기 전에 무슨 일이 일어날지 배지로 알려줍니다.

| 고른 칸 | 배지 | 동작 |
|---|---|---|
| 이미 들어 있음 | `들어 있음 · 빼기` | 그 칸에서 뺍니다 |
| 비었고 다른 칸에도 없음 | `넣기` | 넣습니다 |
| 비었지만 다른 칸에 있음 | `여기로 옮기기` | 새 칸에 넣고 **원래 칸을 비웁니다** |

캐릭터가 하나뿐이면 묻지 않습니다. 카드 아래에 `캐릭터 → C2`처럼 어느 칸에 들어 있는지 나옵니다.

### 칸별 프리셋

편집 창의 **칸별로 나눠서 저장**을 켜면 프리셋 하나가 여러 입력란을 채웁니다.

```
Base Prompt        rain, wet pavement, night
Undesired Content  (비움)
캐릭터 1  프롬프트   holding umbrella
          UC        bad hands
캐릭터 2  프롬프트   wet clothes
```

- **비워둔 칸은 건드리지 않고**, NovelAI에 없는 캐릭터 칸은 건너뛰며 그 사실을 알립니다.
- 채워진 칸이 전부 들어 있으면 빼기, 하나라도 빠져 있으면 넣기입니다.
- 캐릭터 UC는 `프롬프트 / UC` 책갈피 안에 접혀 있습니다. 접힌 쪽에 내용이 있으면 **점**이 찍힙니다.
- 칸 구성은 그 프리셋에만 저장됩니다. 캐릭터 칸은 최대 8칸.
- 모드를 끄면 칸별 내용이 사라지므로 먼저 확인을 받습니다.

카드 아래 배지에 `씬·배경 → Base·C1·C1 UC·C2`처럼 어느 칸을 쓰는지 표시됩니다.

### 중복과 가중치

`{blue eyes}`가 이미 있으면 `blue eyes`를 또 넣지 않습니다. 대소문자·여분 공백·가중치
문법(`{}`, `[]`, `1.2::tag::`)을 벗겨내고 비교합니다.

NovelAI가 캐릭터 칸에 미리 넣어두는 `girl` · `boy`도, 성별이 든 캐릭터 프리셋을 넣을 때
알아서 걷어내 `girl, 1girl`처럼 겹치지 않습니다. `boy` 칸에 `1girl` 프리셋을 넣으면 성별이 교체됩니다.

### 태그 정리

툴바의 **지팡이** 버튼을 누르면 NovelAI 화면 위에 정리 창이 뜹니다.
위 칸에 붙여넣으면 아래 칸에 결과가 **바로** 나옵니다. 무엇을 고쳤는지도 함께 적힙니다.

다른 곳에서 가져온 프롬프트의 **문법만** V5 표준으로 바꿉니다.

| 넣으면 | 나옵니다 |
|---|---|
| `(blue eyes:1.2)` | `1.2::blue eyes::` |
| `{{masterpiece}}` | `1.1::masterpiece::` |
| `{{{ornate dress}}}` | `1.16::ornate dress::` |
| `[wind]` | `0.95::wind::` |
| `(hat:-1)` | `-1::hat::` |
| `(tag:1.0)` | `tag` (곱하기 1은 뺍니다) |
| `a,b,,  c` | `a, b, c` |
| `artoria pendragon \(fate\)` | `artoria pendragon (fate)` |

**건드리지 않는 것** — 태그의 철자와 순서, 줄바꿈, 그리고 `hakurei reimu (touhou)`처럼
이름 뒤에 붙는 괄호입니다. 시리즈명을 가중치로 착각하면 안 되므로 **`:숫자`가 있을 때만**
괄호를 손댑니다. `(sharp focus)`처럼 수치 없이 괄호로만 감싼 것은 바꾸지 않고 알림만 띄웁니다.

맨 아래 **인접한 같은 가중치 병합**을 켜면 `1.1::a::, 1.1::b::`를 `1.1::a, b::`로 붙입니다.
가중치 구간 안으로 쉼표가 들어가는 형태라 결과가 완전히 같다는 확인을 못 했습니다 — 그래서 기본은 꺼져 있습니다.

어휘 검증이나 오탈자 교정은 하지 않습니다. **형태만** 다듬는 도구입니다.

### Opus 사용량 창

푸터의 퍼센트 칩을 누르면 NovelAI 화면 위에 창이 뜹니다. 잔량 추이 그래프, 생성 기록(초 단위 시각),
장당 평균 소모량을 봅니다. 구간은 최근 50장 / 200장 / 전체 중에 고릅니다.

**한 장의 소모량은 원리적으로 알 수 없습니다.** NovelAI가 정수 퍼센트만 알려주기 때문입니다.
대신 여러 번의 하락을 생성 장수로 나눈 **평균을 오차 범위와 함께** 추정하며, 표본이 쌓일수록 정확해집니다.

| 누적 하락 | 대략 장수 | 오차 |
|---|---|---|
| 5%p | ~86장 | ±20% |
| 10%p | ~170장 | ±10% |
| 20%p | ~350장 | ±5% |

**할당량을 쓰는 것은 V5뿐입니다.** `nai-diffusion-5-full` · `nai-diffusion-5-curated`로 생성할 때만
퍼센트가 줄어듭니다. V4.5는 Anlas만 걸리므로 기록표에는 남지만 **장당 평균에서는 빠집니다**(흐리게 표시).

**Anlas가 나간 생성이 있으면 그 이후만 표본으로 씁니다.** 크기를 키운 V5 생성은 Anlas가 나가는데,
그때 할당량까지 함께 깎이는지는 화면에서 확인할 방법이 없습니다(퍼센트가 정수라 한 장은 눈금에 안 잡힙니다).
어느 쪽으로 가정하든 한쪽이 틀리므로 가정하지 않습니다.

**숫자는 항상 보입니다.** 표본이 모자라거나 과금 생성이 섞였을 때도 값을 가리지 않고,
그 아래 작은 글씨로 무엇이 걸려 있는지 적습니다 — 오차 범위, ±10%까지 몇 장이 더 필요한지,
과금 생성이 섞였는지, 이전 구간을 잘랐는지.

퍼센트는 **100을 넘을 수 있습니다.** V5 출시 기념 부스트로 한 번 100%p가 얹혔습니다(30% → 130%).
NovelAI의 **Always Show Usage Limit Bar** 설정과는 무관합니다.

### Anlas

같은 창에 **남은 Anlas**와 생성별 차감액이 함께 나옵니다. 생성 전후 잔액 차이를 그대로 적으므로
퍼센트와 달리 추정이 아니라 실측값입니다.

Opus에서 Anlas가 **0으로 유지되는 조건**은 넷입니다 — **요청당 1장** · 캐릭터 레퍼런스 없음 ·
**가로×세로 ≤ 1,048,576px** · 스텝 ≤ 28. 하나라도 벗어나면 차감됩니다.
특히 **Number of Images를 2 이상으로 두면 첫 장 말고는 전부 과금됩니다**(4장 요청 = −60).
정사각 1024가 기준이 아니라 **픽셀 수**가 기준이라, 832×1216(1,011,712px)은 무료지만 세로를 조금만 늘리면 과금됩니다.

기록표의 Anlas 칸에서 `0`은 "안 깎였다", `—`는 "확인 못 했다"입니다. 둘은 다릅니다.

### 테마 · 이모지 · "Did you mean?"

- **테마** — 설정(⋮)에서 자동 · 밝게 · 어둡게. 자동은 브라우저·운영체제를 따릅니다.
  사이드 패널과 NovelAI 위 창들이 같이 바뀝니다.
- **이모지** — 프리셋 이름 앞에 붙여 목록에서 빠르게 찾습니다. 338개를 주제별 15묶음으로 나눠 뒀습니다 —
  표정 · 인물 · 의상 · 장신구 · 풍경 · 건축 · 동물 · 식물 · 날씨 · 반짝 · 하트·달콤 · 소품 · 도구 · 화풍 · 기호.
  한 줄에 10개씩 보이고 가로 스크롤은 없습니다.
- **"Did you mean?" 끄기** — NovelAI가 태그 DB에 없는 태그마다 띄우는 교정 제안을 숨깁니다. 즉시 반영됩니다.

### 예약 생성

툴바의 예약 버튼(≡⏱)을 누르면 NovelAI 화면 위에 예약 창이 열립니다.

- **여는 순간의 화면이 베이스로 얼어붙습니다** — 프롬프트·UC·캐릭터·모델·크기·스텝.
  창 안에서는 못 고칩니다. 고치려면 창을 닫고 NovelAI에서 바꾼 뒤 다시 여세요.
- 세트를 최대 5개까지, 총 200장까지 예약합니다. 각 세트는 **베이스 + 고른 프리셋들**입니다.
- **V4.5 · V5**의 full · curated에서 씁니다. 그 밖의 모델은 시작을 막습니다.
- V4.5 베이스면 Opus 예측이 `0%`로 나옵니다 — 할당량을 쓰지 않기 때문입니다.
- 시작 전에 예상 시간·Opus·Anlas가 나옵니다. 표본이 모자라면 얼마나 틀릴 수 있는지와
  **몇 장을 더 생성해야 믿을 만해지는지**를 같이 적습니다.

**한 장씩** 요청하고, 한 번에 하나씩만 보내며, 완료를 확인한 뒤 0.4~0.9초 쉬었다 다음을 시작합니다.
생성 자체가 장당 4.5초쯤 걸리므로 간격은 사실상 그쪽이 정합니다 —
딜레이는 요청이 겹치지 않게 하는 장치입니다.
묶어 보내지 않는 이유는 **Opus 무료가 요청당 한 장까지**이기 때문입니다 —
4장을 한 번에 요청하면 나머지 3장은 Anlas가 나갑니다.
실패하면 **재시도하지 않고 즉시 멈춥니다.** Opus 잔량이 10%에 닿아도 멈춥니다.
끝나거나 멈추면 프롬프트와 장수를 원래대로 되돌립니다.

> **긴 큐 전에 NovelAI 설정에서 Auto Download를 켜세요.** 탭이 죽으면 화면 배치가 디스크에
> 남지 않아 결과를 되찾지 못합니다. 50장을 넘기면 창이 이 안내를 띄웁니다.

### 출력 뷰어를 예전처럼

V5부터 생성 결과가 **무한 캔버스** 위에 놓입니다. 넘길 때 카메라가 미끄러지고, 마우스로 끌면
움직이고 줌이 되고, 이미지 모서리가 둥급니다. 되돌리는 스위치는 두 군데에 나뉘어 있습니다.

**NovelAI 쪽** — Settings → Image Generation. 셋 다 기본 꺼짐입니다.

| 켤 것 | 없어지는 것 |
|---|---|
| **Simple Output Viewer** | 캔버스 배치. 지금 생성만 장식 없이 보입니다 |
| **Reduced Motion** | 넘길 때의 카메라 애니메이션 |
| **Lock Output Viewer Camera** | 마우스 패닝·줌 |

**Nib 쪽** — 설정(⋮) → 출력 뷰어 → **이미지 모서리 라운딩 없애기**.
NovelAI에 설정이 없는 둘을 맡습니다 — 모서리 라운딩(8px)과 마우스를 올렸을 때의 확대(98%→100%).
켜고 끄면 즉시 반영됩니다.

**왜 Nib이 다 하지 않나** — 애니메이션과 패닝·줌은 CSS가 아니라 JS가 매 프레임 좌표를 찍는
방식이라, 밖에서 덮으면 애니메이션이 아니라 카메라가 죽어 이미지가 화면 밖으로 나갑니다.
NovelAI의 공식 스위치를 쓰는 편이 정확하고, 업데이트에도 견딥니다.

## 데이터와 백업

라이브러리는 확장 저장소에 있습니다. **브라우저 캐시·쿠키를 지워도 남습니다.**
(NovelAI 자신의 프롬프트 상태는 `localStorage`에 있어 캐시 삭제 시 날아갑니다 — 그건 NovelAI 쪽 동작입니다.)

사라지는 경우는 **확장을 삭제하거나 Chrome 프로필을 초기화할 때**뿐입니다. 설정(⋮)에서:

- **전체 설정 내보내기** — 프리셋과 폴더를 통째로
- **특정 폴더 내보내기** — 폴더를 **1~5개**만 골라서. 5개를 채우면 나머지는 잠깁니다
- **설정 불러오기** — 넣기 전에 확인 창이 뜹니다(아래)
- **자동 백업 폴더 연결** — 한 번 연결해두면 저장할 때마다 그 폴더의 `nib-presets.json`이 갱신됩니다.
  브라우저를 재시작하면 권한이 풀릴 수 있는데, 설정을 열면 상태가 표시되고 버튼을 다시 누르면 재승인됩니다.
- **전체 프리셋 초기화** — 저장된 프리셋을 한 번에 비웁니다. `프리셋만 지우기`(폴더 구조는 남김)와
  `프리셋과 폴더를 모두 지우기` 중에 고르며, **창 안에 내보내기 버튼이 함께 있습니다.**
  자동 백업 파일은 다음 저장 때 함께 비워지므로 남길 것이 있다면 여기서 먼저 내보내세요.

네 가지 모두 **같은 형식**으로 씁니다. 자동 백업 파일에도 폴더가 실립니다.

### 불러오기 창

파일을 고르면 두 칸짜리 창이 뜹니다. 좁으면 위아래로 쌓이고, 560px 이상으로 넓히면 좌우로 펴집니다.

- **왼쪽 — 파일 안의 내용.** 폴더를 아코디언으로 접었다 폅니다. 안에 프리셋 이름과 분류가 보입니다.
- **오른쪽 — 가져오기 제어.** 폴더마다 **이름 유지 / 새 이름 / 제외**를 따로 고릅니다.
  제외한 폴더는 양쪽 칸에서 함께 어두워집니다.
- **중복 이름 경고.** 이미 있는 폴더와 이름이 겹치면 그 줄에서 바로 **기존 폴더에 병합 / 새 이름으로**를
  고릅니다. 창을 옮기지 않습니다. 겹치는 폴더가 둘 이상이면 위에 **전부 병합 / 전부 새 이름** 띠가 나옵니다.
- 정하지 않은 겹침이 남아 있으면 **가져오기 버튼이 잠깁니다.**

프리셋은 `이름 + 분류`가 같으면 덮어쓰고 없으면 추가합니다. 이미 있던 프리셋은 파일 때문에
다른 폴더로 옮겨지지 않습니다 — 폴더 밖에 있던 것만 따라 들어갑니다.
폴더가 없던 옛 `version: 1` 파일도 그대로 읽히며, 그 경우 '폴더 없음' 한 묶음으로 들어옵니다.

## 자주 겪는 문제

| 증상 | 원인과 해결 |
|---|---|
| 목록에 Nib이 안 보임 | 폴더를 잘못 골랐습니다. `manifest.json`이 **바로 안에 있는** 폴더를 고르세요 |
| 툴바에 아이콘이 없음 | 퍼즐 조각 아이콘 → Nib 옆 핀 클릭 |
| 아이콘을 눌러도 패널이 안 열림 | Chrome 114 미만입니다. 업데이트하세요 |
| 프리셋을 눌러도 태그가 안 들어감 | NovelAI 탭을 새로고침하세요. 확장 설치 전에 열려 있던 탭에는 붙지 않습니다 |
| 사용량이 계속 비어 있음 | V5로 한 장 생성해야 기록이 시작됩니다 |
| 카드에 `Base·C1` 같은 배지 | 칸별 프리셋입니다. 의도한 게 아니면 편집에서 "칸별로 나눠서 저장"을 끄세요 |
| 편집 창이 안 열림 | NovelAI 탭이 필요합니다. 새로고침 후 다시 시도하세요 |
